# 矿井瓦斯班测台

检查员上报测点甲烷浓度。达到 1% 时，服务端通过网页套接字把这条报警推到已经打开的页面。页面是手写脚本，没有用组件框架，也没有图表。

检查员可把认定为误报的行放进隔离区，并**必须填写隔离原因**。隔离区里的行默认不出现在总表，但可在时限内恢复回总表；超时未恢复的隔离行自动转为永久隔离，不能再恢复。旁观账号可以查看隔离区，但不能隔离或恢复。隔离、恢复、超时都会通过网页套接字实时推送到已打开的页面。

## 端口

| 服务 | 地址 |
|------|------|
| 页面 | http://localhost:3191 |
| 接口 | http://localhost:8191 |
| PostgreSQL | localhost:54391 |

## 账号

| 用户 | 密码 | 权限 |
|------|------|------|
| gasman | gas123456 | 可上报、可隔离误报行、时限内可恢复 |
| viewer | view123456 | 只能看（总表与隔离区都能看，无任何操作按钮） |

## 隔离规则

- 隔离必须填写原因，原因随隔离区记录展示（含隔离人、隔离时间）。
- 隔离后该行从总表消失，进入隔离区；所有登录用户都能在隔离区看到它。
- 自隔离起 30 分钟内（`QUARANTINE_TTL_MINUTES` 可调整），检查员可一键恢复，行回到总表。
- 超时未恢复：后台每 3 秒清扫一次，将其转为永久隔离，隔离区显示“已永久隔离 / 不可恢复”，任何请求恢复都会被拒绝。
- 网页套接字事件：`reading`（新上报）、`quarantined`（隔离成功）、`restored`（恢复成功）、`quarantine_expired`（超时永久隔离）。


## 验收

1. 用 gasman 登录，列表里回风巷是报警，东翼-12 是正常。
2. 再开一个浏览器窗口同时看列表，上报一个大于等于 1 的测点，两个窗口都会出现新记录。
3. viewer 登录后没有上报表单，也没有隔离/恢复按钮，但能打开隔离区页签查看内容。
4. 用 gasman 在总表给“东翼-12”填写原因并点隔离：东翼从总表消失（总表只剩回风巷），进入隔离区；另一个已打开的页面也会实时刷掉该行。
5. 切到隔离区页签，东翼显示隔离原因、隔离人（gasman）、隔离时间和恢复倒计时；在时限内点恢复，东翼立即回到总表。
6. 再隔离一行并等过恢复时限（或把 `QUARANTINE_TTL_MINUTES` 调小重启）：该行变为“已永久隔离”，恢复按钮消失，接口也拒绝恢复。
