# 矿井瓦斯班测台

检查员上报测点甲烷浓度。达到 1% 时，服务端通过网页套接字把这条报警推到已经打开的页面。页面是手写脚本，没有用组件框架，也没有图表。

检查员可把误报行移入隔离区（必须填原因）。隔离行默认不进总表，在恢复时限（默认 600 秒，可用环境变量 `QUARANTINE_TTL_SECONDS` 调整）内可恢复回总表，超时未恢复转为永久隔离，不能再恢复。viewer 能看隔离区，但不能隔离或恢复。隔离或恢复成功后，套接字会通知已打开的页面刷新列表。

## 端口

| 服务 | 地址 |
|------|------|
| 页面 | http://localhost:3191 |
| 接口 | http://localhost:8191 |
| PostgreSQL | localhost:54391 |

## 账号

| 用户 | 密码 | 权限 |
|------|------|------|
| gasman | gas123456 | 可上报 |
| viewer | view123456 | 只能看 |

## 启动

```bash
cd projects/12-mine-methane-shift
docker compose up --build
```

## 验收

1. 用 gasman 登录，列表里回风巷是报警，东翼-12 是正常。
2. 再开一个浏览器窗口同时看列表，上报一个大于等于 1 的测点，两个窗口都会出现新记录。
3. viewer 登录后没有上报表单。
4. gasman 把东翼-12 隔离并填原因，总表只剩回风巷，其他已打开的页面也会刷掉该行；viewer 打开隔离区能看到这条记录和原因，但没有隔离/恢复按钮。
5. 时限内在隔离区点恢复，东翼-12 回到总表；超时未恢复的记录显示永久隔离，恢复接口拒绝。
